BLACK BACKGROUND / ORIGINAL PDF VIEWER

UPLOAD THE CONTENTS OF THIS ZIP, NOT THE ZIP ITSELF
Copy index.html, style.css, viewer.js, portfolio.pdf, .nojekyll and the whole
vendor folder directly into your existing local Portfolio repository.
Replace matching files. Keep your .git folder and README.md.
Commit to main and Push origin in GitHub Desktop. Wait for deployment and
hard-refresh (Windows Ctrl+F5; Mac Cmd+Shift+R).
The old pages folder and pages.json are unused by this viewer; they may remain.

YOUR PDF IS UNCHANGED
The included portfolio.pdf is a byte-for-byte copy of your latest attachment:
portfolio1_under20_highquality_v2(2).pdf
19,747,347 bytes. SHA-256:
d8cf71345f00faf59df4960ff4ea9288676c2d9cce2e9973528b7ad4b8340938
No PDF compression, resampling, flattening, quality adjustment or edits.
There are no exported page images in this package.

The browser reads the original PDF with bundled PDF.js and draws visible pages
at the current display/zoom resolution, as PDF readers do. It does not modify
the file. The download button delivers that same original PDF.

FEATURES
Pure black background (#000), white side arrows, bottom page slider and zoom,
fullscreen control, desktop paired pages and single-page mobile view.
Short 3D turn for adjacent desktop spreads; slide for cover/mobile/large jumps.
PDF hyperlinks are read from the actual attachment, not old image coordinates.
Reduced-motion preference respected. Mobile swipe navigation supported.
Fullscreen depends on browser support.

VALIDATION
PDF byte identity and JavaScript syntax checked. Bundled PDF.js opened all
43 pages and rendered sample cover, drawing and end pages successfully.
The drawing sample was visually inspected. Full live-browser interaction testing
has not been completed for this new PDF-based viewer.
Complex drawing pages may take longer to display than the former image viewer.
Use a modern browser. Open through GitHub Pages, not by double-clicking HTML.
